# 🚦 TravelCity 交通城市

一款在瀏覽器中執行的城市交通模擬遊戲。靈感來自 *Trafficity* 與 *Highway Co*：
以**無網格的自由道路建設**搭配**代理式（Agent-based）微觀交通模擬**，
並用簡化的城市經濟驅動交通需求。不需要安裝或建置，打開網頁就能玩。

## 遊戲特色

### 🚗 微觀交通模擬
- 每輛車都是獨立代理人，有自己的出發地、目的地與路線。
- 跟車採用 **IDM（Intelligent Driver Model）**，會加速、煞車、排隊並保持安全距離。
- **變換車道**：為了轉彎會提前切到正確車道；遇到前方慢車或車潮，會評估相鄰車道是否較快並主動切換（MOBIL 式判斷，也有靠右行駛傾向）。
- **即時路線選擇**：以 Dijkstra 演算法依各路段的即時車速規劃路線，行駛途中會定期重新選路，塞車時會繞道。
- 路口行為：紅綠燈（含黃燈、全紅清道、左轉待轉）、讓路、全向停車、路權高低、匯流與衝突點判斷，以及「不堵塞路口」的規則；等太久的駕駛會接受較小的車距。路口內有交叉的車時依時間窗判斷（對方會先開過去、或自己能在對方到達前開過去就走），不必等對方整台車開過；在錯的車道上要換車道時，旁邊車道的後車會禮讓留出空隙，換不過去就改走這條車道能走的方向。
- 決定性模擬：固定時間步長與種子亂數。

### 🛣️ 自由道路建設
- 任意角度鋪路，可畫**直線或三點曲線**；與既有道路交會時自動產生路口。靠近地塊的後緣或側邊時會吸附成剛好貼齊（留 1.5 m 人行道）。鋪路時顯示與起點道路的夾角，接近平行 / 45° / 垂直會自動對齊（Shift 每 15°）；接到另一條路時，接點會沿那條路滑動，讓新路垂直（或 45°）接上。超出路口不到 12 m 的多餘路段會自動修掉，不會留下短短的死路。
- **13 種道路類型**：鄉間小路、市區道路、單行道（1/2 線）、大道、林蔭大道、匝道、雙線匝道、快速道路、高速公路（3+3 / 4+4）、單向高速（3 / 4 線）。車道數不同的道路相接時會自動縮減或增加外側車道（例如四線轉三線）。
- **6 種高度層級**：深層隧道、隧道、地面、高架一～三層。不同高度的道路交叉時不會相連，可蓋出**立體交叉 / 交流道**；有坡度限制，地面道路不能跨越水域。
- **道路建設工具**（`R`）：道路、圓環（`O`）、交流道（`I`）、升級（`U`）合併在同一個工具，副工具列有道路斷面縮圖（含每條車道的行車方向，一眼看出單行道）與交流道平面縮圖。
- **圓環**：一鍵把路口改建成圓環，環道車輛擁有路權。進入圓環的臨界間距約 3 秒（環道上正常行駛的車不必等它整段開走），進出口約 20 km/h。
- **停車場 / 社區出入口**：場內道路接到一般道路的地方不算十字路口：沒有斑馬線與停止線、路口範圍很小，主線標線一路畫過去；道路另一側沒有路口，分區格子可以一路排過去。
- **交流道**：16 種依真實設計繪製的模板（苜蓿葉為正圓環道、外側右轉匝道自動貼著內側匝道；SPUI 左轉匯集到單一號誌、右轉走自由右轉匝道；半定向 T 左右對稱），移到兩條不同高度道路的交叉處可直接套用，空地上則連主線一起建造；`Q` / `E` 旋轉。整組價格 $45,000～$60,000。
  - 服務型：鑽石型、部分苜蓿葉 A / B（Parclo）、分岔鑽石（DDI）、單點式（SPUI）
  - 系統型：苜蓿葉、苜蓿堆疊、渦輪型、二層渦輪、渦輪堆疊混合、風車型、編織型、二層圓環、三層圓環
  - T 字型：喇叭型、半定向 T
- **路口編輯**（用選取工具點路口）：切換紅綠燈 / 全向停車 / 自動路權，調整各時相秒數、選擇「各方向輪流」或「對向同時通行」、開啟感應式號誌，設定讓路標誌。**車道連接用拖曳**：從進入車道拖到離開車道就新增，同樣再拖一次就移除，可做出「只能直行」「只能左轉」等車道；路面會畫出對應的轉向箭頭。
- **道路升級**：直接把既有道路換成其他類型，或反轉單行道方向。

### 🏙️ 簡化城市經濟
- **住宅**：居民要通勤上班、去商店購物；討厭工業污染與高速公路噪音，通勤太久也會不滿。
- **工業**：需要工人與外部運來的原料，生產商品後以貨車送到商店。
- **商業**：需要員工、商品與顧客。顧客有開車來的、也有附近 450 m 內住宅走路來的；滿意度看最近約 10 小時的來客是否達到依吸引力（容量 × 店種）分到的應有份額，不會每晚掉到零。加油站的顧客是路過的車；辦公大樓不需要顧客與商品。
- **分區格子**：以 6 m × 6 m 為一格，按住沿路拖曳、往外拉深即可劃設（拖曳時顯示格數），可以沿直行方向一路拖過路口，**完全免費**。一次拖曳的範圍會依最大尺寸切成數塊地塊：
  - **依人口解鎖**（人口以曾達到的最高人口計，人口減少不會再鎖回去）：所有分區一開始最大 12×12；**沙盒模式一開始就全部解鎖**

    | 城市稱號 | 人口 | 解鎖 |
    | --- | --- | --- |
    | 小村莊 | 0 | 低密度住宅、商業、工業（最大 12×12） |
    | 小鎮 | 750 | 大眾運輸（公車總站 12×12） |
    | 市鎮 | 1,000 | 中密度住宅（12×12） |
    | 城市 | 2,500 | 商業 18×18、中密度 18×18、公車總站 16×16 |
    | 大城市 | 3,000 | 高密度住宅（12×12）、工業 32×32、高科技工廠（半導體晶圓廠、電池 / 電子零件廠） |
    | 大都會 | 5,000 | 商業 30×30、高密度 24×24 |

  - 最大尺寸：低密度 12×12；中密度 18×18；高密度 24×24；商業 30×30；工業 32×32；公車總站 16×16
  - **臨路道路也限制地塊大小**：鄉間小路旁最大 6×6、市區道路（與 1 線單行道）12×12、大道（與 2 線單行道）18×18、林蔭大道不限（只看分區本身的上限）
  - 城市稱號下方有往下一階段的進度條；點稱號或右上角「里程碑」可看各階段的人口、解鎖內容與進度
  - 商業：商店街、超級市場、加油站、純停車場、辦公大樓（工作多）；5×5 格以上可能是飯店（帶來外地旅客過夜）；15×15 格以上可能是大型量販店、購物中心或附立體停車場的購物中心。附停車場的商業會開一條場內道路進停車場，停車場畫有停車格。地塊後方緊鄰另一條道路時會打通，但設柵欄閘門：只有進出這裡的車能走，不會被當捷徑
  - 所有地塊最小 2×2 格；不同道路的格子會合併，不會重疊
  - 跨縣市公車：**跨縣市公車站**（人口 1000 解鎖，最大 12×12）與**跨縣市公車總站**（人口 2500，最大 20×20，同時也是一般公車總站，一半的停車格給市內路線）。連節公車（18 m）從站內開到每個接通的外部連線，約 2 個遊戲小時後載著外地乘客開回來；往返外地的居民、外地來上班 / 購物的人與旅客有三成多改搭（全市都會來搭，回程也搭）。候車 15 人以上或最早的人等了 3 個遊戲小時才發車。9×6 格以上有中央車道與兩側的連節公車停車格
  - 計程車（人口 750 解鎖）：**計程車派遣中心**（最大 10×10，夠大時中央車道兩側都是計程車位，全市都能派車）與**計程車招呼站**（最大 4×4，路邊幾個計程車位，派車範圍 1.8 km）。家裡沒車可開、附近又沒有公車可搭的居民（以及少數有車的居民）會叫車：從最近、有停著計程車、範圍涵蓋的站派車，接到客人後送到目的地，再開回最近有空位的站停好
  - **鐵路**（大眾運輸分區，人口 1,000 解鎖總站與車站、2,500 解鎖貨運站）：
    - 道路工具多了「鐵路（雙線）」：只有列車行駛，與道路平面相交是平交道（列車約 14 秒內會到時車輛一律停下）；鐵路與道路不能互相改建
    - 地圖邊緣有一條外部鐵路，小鎮開局時延伸到小鎮外圍
    - 車站沿道路劃設，但地塊後方或側邊 30 m 內要有地面鐵軌（月台在鐵軌上）；劃錯會提示
    - **鐵路總站**：列車從這裡發車，依序停靠同一條鐵路上的各車站，到底再折返；可在資訊面板花 $8,000 **附設公車轉運站**（前方一排公車停車格、成為公車總站，公車與列車在這裡轉乘）
    - **車站**：列車停靠；住家或目的地 800 m 內有車站的居民會搭火車
    - **貨運站**：貨運列車每 4 個遊戲小時從外部鐵路開來，卸下原料、載走外銷商品；附近 3 km 內的工廠優先從這裡用貨車拿原料，外銷商品也送到這裡
  - 大眾運輸（公車總站）：拖曳劃設時提示會顯示會有幾個公車停車位（＝最多能派出幾台公車）；劃了就蓋（不看需求）；有公車庫、調度辦公室與一格格公車停車位，停車位數就是總站最多能派出的公車數
  - 工業：園區內會開出真正的場內道路（淺灰色），員工與貨車都開進園區；功能隨機（製造、物流倉儲、食品加工、化工、科技園區；人口 3,000 以上還有半導體晶圓廠、電池 / 電子零件廠，各有不同的工作數與貨運量）。工業污染目前不影響住宅
- 車子不會憑空消失：抵達時沿曲線開進一個空的停車位停好，出發時從停車位開出來再加入車流；每個車位都接到車頭前方的道路（臨路車位接前面的街道、巷道 / 停車場旁的車位接場內道路），開進開出不會穿過建物或其他車位。每棟建築記錄實際停著幾輛車，存檔也會保存。
  - 住宅全部是室外停車：獨棟住宅前院並排兩個車位、連棟住宅與街廓臨路一排停車格，夠大的地塊開巷道、巷道兩側是停車格
  - 商店街：停車格在店面前方（部分是左進右出的前庭），有場內道路的在後方停車場；辦公大樓 / 飯店有臨路停車格與地下停車場；工業區臨路有員工停車場；加油站停在加油島旁
  - 巷道、停車場車道等場內道路只給進出該建築的車使用，不會被當成迴轉道或捷徑
  - 貨車有自己的卸貨區：工業區主幹道兩側的卸貨位、商業臨路的黃框卸貨區；原料貨車停進工廠，送貨的貨車在商店卸完貨後開回工廠
  - 量販店、購物中心、超市的停車場是**單向環狀動線、一進一出**：入口在臨路車道的上游端、出口在下游端，只能右進右出；進場的車沿前方車道分到各停車車道，離場的車經後方車道從出口離開。等著進場的車往上游回堵，不會擋住出口（左轉進出的車停在主要道路上等，回堵到出口時整個停車場會卡死）
  - 純停車場的每條車道都接到前面的街道（多個出入口）；車子轉進車位時會等旁邊的車道、路口淨空，不會穿過其他車
  - 高密度住宅：住戶的車大多停在**地下停車場**或旁邊的**立體停車場**，臨路只有一排訪客車位；購物中心也可能附立體停車場。停車場前有一條單向車道（右進右出），入口與出口車道分開，排隊進場的車不會停在外面的道路上
  - 家裡的車都開走時，其他居民搭大眾運輸 / 走路，不會從房子憑空開出車
- **公車**：有公車總站時，系統自動在人多、工作多的建築前設站牌（彼此至少相距 240 m），依方位分成數條環狀路線（每條最多 9 站），每條路線都從離總站最近的**轉乘站**出發，可以換一次車；公車數依發車間隔決定（每條路線最多 8 台）。站序依實際行駛方向（公車到站後只能順著原方向開走）排成總行駛時間最短（2-opt），很少繞回頭或迴轉。站牌離路口 10～30 m（路段越長越遠；臨路路段太短時改設在附近較長的道路），站牌處路面往外加寬成**公車停靠區**：公車快到站時先靠到最外側車道、開進停靠區上下客，後面的車直接開過去；沒有人要上下車就不停靠。分區工具裡的「🚏 公車站牌」可以手動放置站牌（免費，再點一次移除），附近有公車總站時一定會排進路線。每個遊戲日重新規劃，位置沒變的站牌沿用原站。家裡沒車可開、或選擇搭公車的居民，若起點與目的地 450 m 內都有站牌（直達或轉乘一次到得了），就走到站牌等車；等太久會改走路。點選總站可看到各路線實際行駛的道路、候車、轉乘與載客人數。
- **日式風格建築**（車輛仍靠右行駛），有立體感：陰影從建物底部投射、牆面有窗戶與明暗、屋簷外伸，高樓會遮住後方。
  - 外牆以白、米、淺灰的外牆板為主，也有木色與深色的現代住宅；屋頂是黑灰 / 藍灰的日本瓦、褐色瓦與彩色鋼板；一成的樹是櫻花
  - 低密度：兩層樓的透天（寄棟四坡或切妻雙坡、坡度較緩），三成是平屋頂的現代箱型住宅；前院水泥磚圍牆或綠籬、停車位、庭院樹
  - 中密度：兩層、外走廊、鋼板屋頂的アパート，與三～五層、每層陽台的低層公寓大樓（等級越高越多），排與排之間有圍牆與綠地
  - 高密度：平行排列的板狀大樓（團地，每層陽台、大樓間是綠地），夠大的街區有塔式住宅（タワーマンション）與低層裙樓
  - 商業：4.5～9 m 寬的店舖兼住宅組成商店街（平屋頂或日本瓦、一樓店面，部分掛直立看板），小地塊有一層樓的便利商店；飯店為平屋頂的商務飯店與日式庭園；大型辦公大樓是一段段內縮的玻璃帷幕摩天大樓
  - 工業：鋼板外牆的廠房（鋸齒屋頂或低斜度鋼板屋頂、紅白煙囪）、物流倉庫天窗、食品廠筒倉、化工儲槽區、綠屋頂科技園區；園區內不留空地，沒蓋廠房的街區是貨櫃堆場
- 開局有三種：**完整城市路網**（整張地圖已鋪好高架高速公路與交流道、林蔭大道十字主軸、外環大道、200 m 棋盤街廓、東西向鐵路與鐵路總站 / 車站 / 貨運站，位置依地形避開水域、過河處架橋；住宅 / 商業 / 工業由自動發展劃設）、**小鎮**（棋盤狀街道與三條大道，高速公路接進市區的那條改為林蔭大道（3+3，車道數與高速公路相同），只有道路與分區，約 6 個遊戲小時後才開始有人進駐）或**空白地圖**（只有外部連線，沒有分區、預設不自動發展，從零開始）。工業區與住宅至少相隔 250 m。
- 空地塊在該類需求超過門檻（需求條上的虛線，20%）時才會蓋起建築，自動劃設分區的門檻更高（35%），城市依住 / 商 / 工的需求成長；建築會依滿意度升級或衰退，甚至被廢棄（分區保留，之後可再發展）。開啟**自動發展**時，城市也會自己在路旁劃設大小不一的分區。
- **外部連線**：地圖邊緣的高速公路 / 聯外道路帶來過境車流、外地通勤者與原料貨車。
- 收入來自稅收與過路費，支出則是道路與號誌的維護費；所有道路類型與高度層級一開始就全部開放。
- 需求除了住 / 商 / 工的比例之外，還有一股持續的成長壓力（一直有人想搬進來、開店、設廠），交通壅塞或行程失敗多時會被抵銷。
- 交通回饋：壅塞或行程失敗太多時，沒有人想搬進來，城市成長會停下來。
- 程式出錯時遊戲不會停住：自動截圖並記錄錯誤，上方出現紅色「⚠ 錯誤」按鈕，可以複製 / 下載截圖，一鍵開啟預先填好的 GitHub issue（error 標籤）回報。
- 卡死排除：車道最前面的車停住超過約 6 個遊戲小時（路口互卡、整串車動不了）會被移除，後面的車就能動；統計頁會顯示排除了幾台。

### 🗺️ 隨機地圖
- 地圖 3.6 km × 3.6 km（舊存檔維持 2.4 km）。
- **4 種生態系**：溫帶平原、沙漠綠洲、寒帶雪原、熱帶群島（河流、湖泊、島嶼與樹林）。
- **4 種難度**：沙盒（無限資金、分區一開始全部解鎖）、簡單、普通、困難。
- 以種子程序化生成，可無限重玩。

## 執行

純 HTML + JavaScript（ES Modules），沒有任何相依套件，但 ES Modules 需要透過 HTTP 載入：

```bash
python3 -m http.server 8080
```

然後打開 <http://localhost:8080>。也可以直接部署到 GitHub Pages（Settings → Pages → 從 `main` 分支根目錄發布）。

## 測試

模擬核心（路網、交通、經濟）不依賴 DOM，可用 Node.js 18 以上無頭執行：

```bash
npm test   # = node tests/sim.test.js && node tests/interchange.test.js
```

測試內容包含：建立世界、連接外部道路、號誌與全向停車、圓環改建、道路升級與拆除、高架跨越、存讀檔，以及連續模擬 20 遊戲小時的行程成功率；交流道測試會逐一建造每種模板，讓 12 種行向的車流全部通過，並檢查沒有車輛靠死路迴轉繞行。

## 程式架構

| 檔案 | 說明 |
| --- | --- |

| `js/terrain.js` | 程序化地形、河流、樹木 |
| `js/network.js` | 節點、路段、車道、路口車道連接與衝突、號誌時相、道路規劃與建造、圓環 |
| `js/routing.js` | 以有向路段為節點、即時車速為成本的路徑搜尋 |
| `js/traffic.js` | 車輛代理人：IDM、變換車道、路口通行判斷、重新選路、停車、公車到站 |
| `js/transit.js` | 大眾運輸：站牌與公車路線自動規劃、派車、乘客上下車 |
| `js/city.js` | 建築、行程產生、滿意度、成長、財務 |
| `js/worldgen.js` | 外部連線與初始小鎮 |
| `js/render.js` | Canvas 2D 繪圖（多層道路、車輛、號誌、熱圖、路口編輯） |
| `js/lotart.js` | 地塊上的建築圖形（日式風格：透天、アパート、公寓大樓、團地與塔式住宅、商店街、便利商店、飯店、量販店、工業園區） |
| `js/thumbs.js` | 工具列縮圖（道路斷面、圓環、交流道） |
| `js/interchange.js` | 交流道模板：幾何、高度剖面、試建與建造 |
| `js/tools.js` | 玩家工具與輸入 |
| `js/ui.js` | 介面面板與對話框 |
| `js/main.js` | 主迴圈、存讀檔 |

模擬時間：每 0.1 秒一步，1 模擬秒 = 4 遊戲分鐘。參考 Cities: Skylines 的時間膨脹：車子照常速開，時鐘走得快很多（一般速度一天約 4 分鐘、▶▶ 約 2 分鐘、▶▶▶ 約 45 秒）；行程產生率依模擬秒計算，所以時鐘加快不會讓路上車量暴增，但城市成長與收支會加快。
