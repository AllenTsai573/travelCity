# 🚦 TravelCity 交通城市

一款在瀏覽器中執行的城市交通模擬遊戲。靈感來自 *Trafficity* 與 *Highway Co*：
以**無網格的自由道路建設**搭配**代理式（Agent-based）微觀交通模擬**，
並用簡化的城市經濟驅動交通需求。不需要安裝或建置，打開網頁就能玩。

## 遊戲特色

### 🚗 微觀交通模擬
- 每輛車都是獨立代理人，有自己的出發地、目的地與路線。
- 跟車採用 **IDM（Intelligent Driver Model）**，會加速、煞車、排隊並保持安全距離。
- **變換車道**：為了轉彎會提前切到正確車道；遇到前方慢車或車潮，會評估相鄰車道是否較快並主動切換（MOBIL 式判斷，也有靠右行駛傾向）。
- **即時路線選擇**：以 Dijkstra 演算法依各路段的即時車速規劃路線，行駛途中會定期重新選路，塞車時會繞道。
- 路口行為：紅綠燈（含黃燈、全紅清道、左轉待轉）、讓路、全向停車、路權高低、匯流與衝突點判斷，以及「不堵塞路口」的規則；等太久的駕駛會接受較小的車距。
- 決定性模擬：固定時間步長與種子亂數。

### 🛣️ 自由道路建設
- 任意角度鋪路，可畫**直線或三點曲線**；與既有道路交會時自動產生路口。
- **13 種道路類型**：鄉間小路、市區道路、單行道（1/2 線）、大道、林蔭大道、匝道、雙線匝道、快速道路、高速公路（3+3 / 4+4）、單向高速（3 / 4 線）。車道數不同的道路相接時會自動縮減或增加外側車道（例如四線轉三線）。
- **6 種高度層級**：深層隧道、隧道、地面、高架一～三層。不同高度的道路交叉時不會相連，可蓋出**立體交叉 / 交流道**；有坡度限制，地面道路不能跨越水域。
- **圓環工具**：一鍵把路口改建成圓環，環道車輛擁有路權。
- **交流道工具**（`I`）：16 種依真實設計繪製的模板，移到兩條不同高度道路的交叉處可直接套用，空地上則連主線一起建造；`Q` / `E` 旋轉。
  - 服務型：鑽石型、部分苜蓿葉 A / B（Parclo）、分岔鑽石（DDI）、單點式（SPUI）
  - 系統型：苜蓿葉、苜蓿堆疊、渦輪型、二層渦輪、渦輪堆疊混合、風車型、編織型、二層圓環、三層圓環
  - T 字型：喇叭型、半定向 T
- **路口編輯**：切換紅綠燈 / 全向停車 / 自動路權，調整各時相秒數、選擇「各方向輪流」或「對向同時通行」、開啟感應式號誌，設定讓路標誌，並可**逐條新增或移除車道連接**。
- **道路升級**：直接把既有道路換成其他類型，或反轉單行道方向。

### 🏙️ 簡化城市經濟
- **住宅**：居民要通勤上班、去商店購物；討厭工業污染與高速公路噪音，通勤太久也會不滿。
- **工業**：需要工人與外部運來的原料，生產商品後以貨車送到商店。
- **商業**：需要員工、商品與顧客。
- 建築會依滿意度升級或衰退，甚至被廢棄。城市可依 R/C/I 需求**自動發展**，也可以手動劃設分區。
- **外部連線**：地圖邊緣的高速公路 / 聯外道路帶來過境車流、外地通勤者與原料貨車。
- 收入來自稅收與過路費，支出則是道路與號誌的維護費；所有道路類型與高度層級一開始就全部開放。
- 交通回饋：壅塞或行程失敗太多時，沒有人想搬進來，城市成長會停下來。

### 🗺️ 隨機地圖
- **4 種生態系**：溫帶平原、沙漠綠洲、寒帶雪原、熱帶群島（河流、湖泊、島嶼與樹林）。
- **4 種難度**：沙盒（無限資金）、簡單、普通、困難。
- 以種子程序化生成，可無限重玩。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `V` | 選取（查看車輛、建築、路段、路口） |
| `R` | 道路工具（左鍵連續鋪路，右鍵 / `Esc` 結束） |
| `C` | 切換彎道模式 |
| `[` `]` | 切換高度層級 |
| `,` `.` | 切換道路類型 |
| `Shift` / `Alt` | 角度吸附 / 停用吸附 |
| `O` | 圓環 |
| `I` | 交流道（`Q` / `E` 旋轉） |
| `U` | 升級道路 |
| `J` | 路口編輯 |
| `Z` | 分區（可拖曳） |
| `B` | 拆除 |
| `H` | 壅塞熱圖 |
| `空白鍵` | 暫停 |
| `1` `2` `3` | 1× / 3× / 8× 速度 |
| 滑鼠拖曳 / `WASD` | 平移 |
| 滾輪 / 雙指 | 縮放 |

遊戲每 3 遊戲小時自動存檔到瀏覽器，也可以從「選單」匯出 / 匯入存檔檔案。

## 執行

純 HTML + JavaScript（ES Modules），沒有任何相依套件，但 ES Modules 需要透過 HTTP 載入：

```bash
python3 -m http.server 8080
```

然後打開 <http://localhost:8080>。也可以直接部署到 GitHub Pages（Settings → Pages → 從 `main` 分支根目錄發布）。

## 測試

模擬核心（路網、交通、經濟）不依賴 DOM，可用 Node.js 18 以上無頭執行：

```bash
npm test   # = node tests/sim.test.js && node tests/interchange.test.js
```

測試內容包含：建立世界、連接外部道路、號誌與全向停車、圓環改建、道路升級與拆除、高架跨越、存讀檔，以及連續模擬 20 遊戲小時的行程成功率；交流道測試會逐一建造每種模板，讓 12 種行向的車流全部通過，並檢查沒有車輛靠死路迴轉繞行。

## 程式架構

| 檔案 | 說明 |
| --- | --- |
| `js/config.js` | 道路類型、高度層級、難度、生態系、分區等參數 |
| `js/util.js` | 亂數、雜訊、折線幾何、二元堆積 |
| `js/terrain.js` | 程序化地形、河流、樹木 |
| `js/network.js` | 節點、路段、車道、路口車道連接與衝突、號誌時相、道路規劃與建造、圓環 |
| `js/routing.js` | 以有向路段為節點、即時車速為成本的路徑搜尋 |
| `js/traffic.js` | 車輛代理人：IDM、變換車道、路口通行判斷、重新選路 |
| `js/city.js` | 建築、行程產生、滿意度、成長、財務 |
| `js/worldgen.js` | 外部連線與初始小鎮 |
| `js/render.js` | Canvas 2D 繪圖（多層道路、車輛、號誌、熱圖、路口編輯） |
| `js/interchange.js` | 交流道模板：幾何、高度剖面、試建與建造 |
| `js/tools.js` | 玩家工具與輸入 |
| `js/ui.js` | 介面面板與對話框 |
| `js/main.js` | 主迴圈、存讀檔 |

模擬時間：每 0.1 秒一步，1 模擬秒 = 0.5 遊戲分鐘（1× 速度下一天約 48 分鐘）。
