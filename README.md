# 🚦 TravelCity 交通城市

一款在瀏覽器中執行的城市交通模擬遊戲。靈感來自 *Trafficity* 與 *Highway Co*：
以**無網格的自由道路建設**搭配**代理式（Agent-based）微觀交通模擬**，
並用簡化的城市經濟驅動交通需求。不需要安裝或建置，打開網頁就能玩。

## 遊戲特色

### 🚗 微觀交通模擬
- 每輛車都是獨立代理人，有自己的出發地、目的地與路線。
- 跟車採用 **IDM（Intelligent Driver Model）**，會加速、煞車、排隊並保持安全距離。
- **變換車道**：為了轉彎會提前切到正確車道；遇到前方慢車或車潮，會評估相鄰車道是否較快並主動切換（MOBIL 式判斷，也有靠右行駛傾向）。
- **即時路線選擇**：以 Dijkstra 演算法依各路段的即時車速規劃路線，行駛途中會定期重新選路，塞車時會繞道。
- 路口行為：紅綠燈（含黃燈、全紅清道、左轉待轉）、讓路、全向停車、路權高低、匯流與衝突點判斷，以及「不堵塞路口」的規則；等太久的駕駛會接受較小的車距。
- 決定性模擬：固定時間步長與種子亂數。

### 🛣️ 自由道路建設
- 任意角度鋪路，可畫**直線或三點曲線**；與既有道路交會時自動產生路口。靠近地塊的後緣或側邊時會吸附成剛好貼齊（留 1.5 m 人行道）。鋪路時顯示與起點道路的夾角，接近平行 / 45° / 垂直會自動對齊（Shift 每 15°）；接到另一條路時，接點會沿那條路滑動，讓新路垂直（或 45°）接上。超出路口不到 12 m 的多餘路段會自動修掉，不會留下短短的死路。
- **13 種道路類型**：鄉間小路、市區道路、單行道（1/2 線）、大道、林蔭大道、匝道、雙線匝道、快速道路、高速公路（3+3 / 4+4）、單向高速（3 / 4 線）。車道數不同的道路相接時會自動縮減或增加外側車道（例如四線轉三線）。
- **6 種高度層級**：深層隧道、隧道、地面、高架一～三層。不同高度的道路交叉時不會相連，可蓋出**立體交叉 / 交流道**；有坡度限制，地面道路不能跨越水域。
- **道路建設工具**（`R`）：道路、圓環（`O`）、交流道（`I`）、升級（`U`）合併在同一個工具，副工具列有道路斷面縮圖（含每條車道的行車方向，一眼看出單行道）與交流道平面縮圖。
- **圓環**：一鍵把路口改建成圓環，環道車輛擁有路權。
- **交流道**：16 種依真實設計繪製的模板（苜蓿葉為正圓環道、外側右轉匝道自動貼著內側匝道；SPUI 左轉匯集到單一號誌、右轉走自由右轉匝道；半定向 T 左右對稱），移到兩條不同高度道路的交叉處可直接套用，空地上則連主線一起建造；`Q` / `E` 旋轉。整組價格 $45,000～$60,000。
  - 服務型：鑽石型、部分苜蓿葉 A / B（Parclo）、分岔鑽石（DDI）、單點式（SPUI）
  - 系統型：苜蓿葉、苜蓿堆疊、渦輪型、二層渦輪、渦輪堆疊混合、風車型、編織型、二層圓環、三層圓環
  - T 字型：喇叭型、半定向 T
- **路口編輯**：切換紅綠燈 / 全向停車 / 自動路權，調整各時相秒數、選擇「各方向輪流」或「對向同時通行」、開啟感應式號誌，設定讓路標誌。**車道連接用拖曳**：從進入車道拖到離開車道就新增，同樣再拖一次就移除，可做出「只能直行」「只能左轉」等車道；路面會畫出對應的轉向箭頭。
- **道路升級**：直接把既有道路換成其他類型，或反轉單行道方向。

### 🏙️ 簡化城市經濟
- **住宅**：居民要通勤上班、去商店購物；討厭工業污染與高速公路噪音，通勤太久也會不滿。
- **工業**：需要工人與外部運來的原料，生產商品後以貨車送到商店。
- **商業**：需要員工、商品與顧客。
- **分區格子**：以 6 m × 6 m 為一格，按住沿路拖曳、往外拉深即可劃設（拖曳時顯示格數），**完全免費**。一次拖曳的範圍會依最大尺寸切成數塊地塊：
  - 低 / 中密度住宅：最大 12×12 格；高密度住宅：最大 24×24 格
  - 商業：最大 30×30 格。商店街、超級市場、加油站、純停車場、辦公大樓（工作多）；5×5 格以上可能是飯店（帶來外地旅客過夜）；15×15 格以上可能是大型量販店或購物中心。附停車場的商業會開一條場內道路進停車場，停車場畫有停車格。地塊後方緊鄰另一條道路時會打通，但設柵欄閘門：只有進出這裡的車能走，不會被當捷徑
  - 所有地塊最小 2×2 格；不同道路的格子會合併，不會重疊
  - 大眾運輸（公車總站）：最大 16×16 格，劃了就蓋（不看需求）；有公車庫、調度辦公室與一格格公車停車位，停車位數就是總站最多能派出的公車數
  - 工業：最大 32×32 格，園區內會開出真正的場內道路（淺灰色），員工與貨車都開進園區；功能隨機（製造、物流倉儲、食品加工、化工、科技園區，各有不同的工作數、貨運量與污染）
- 車子不會憑空消失：抵達時沿曲線開進一個空的停車位停好，出發時從停車位開出來再加入車流；每個車位都接到車頭前方的道路（臨路車位接前面的街道、巷道 / 停車場旁的車位接場內道路），開進開出不會穿過建物或其他車位。每棟建築記錄實際停著幾輛車，存檔也會保存。
  - 住宅全部是室外停車：獨棟住宅前院並排兩個車位、連棟住宅與街廓臨路一排停車格，夠大的地塊開巷道、巷道兩側是停車格
  - 商店街：停車格在店面前方（部分是左進右出的前庭），有場內道路的在後方停車場；辦公大樓 / 飯店有臨路停車格與地下停車場；工業區臨路有員工停車場；加油站停在加油島旁
  - 巷道、停車場車道等場內道路只給進出該建築的車使用，不會被當成迴轉道或捷徑
  - 貨車有自己的卸貨區：工業區主幹道兩側的卸貨位、商業臨路的黃框卸貨區；原料貨車停進工廠，送貨的貨車在商店卸完貨後開回工廠
  - 大型停車場的每條車道都是真的車道，而且每條都接到前面的街道（多個出入口，不會整個停車場塞在一個出口）；車子轉進車位時會等旁邊的車道、路口淨空，不會穿過其他車
  - 家裡的車都開走時，其他居民搭大眾運輸 / 走路，不會從房子憑空開出車
- **公車**：有公車總站時，系統自動在人多、工作多的建築前設站牌（彼此至少相距 280 m），依方位分成數條環狀路線（每條最多 7 站，從離總站最近的站開始以最近鄰排序），公車數依發車間隔決定。家裡沒車可開、或選擇搭公車的居民，若起點與目的地 350 m 內有同一條路線的站牌，就走到站牌等車；等太久會改走路。點選總站可看到各路線實際行駛的道路、候車與載客人數。
- **歐洲風格建築**，有立體感：陰影從建物底部投射、牆面有一格格的窗戶與明暗，高樓會遮住後方。
  - 立面顏色多樣：灰泥、粉彩、北歐港口式的鮮豔色彩、紅磚；屋頂有多種紅陶瓦、石板瓦、銅綠色
  - 低密度：紅陶瓦 / 石板瓦的獨棟住宅（雙坡或四坡屋頂、L 型、煙囪、太陽能板），前院樹籬與停車位
  - 中密度：每戶 5.5～7.5 m 寬的連棟住宅，立面各有顏色，部分是山牆朝街的荷蘭式，後院以樹籬分隔
  - 高密度：周邊式街廓（建物沿地塊四周圍出中庭花園，立面一段段不同顏色與高度，部分為巴黎式折線屋頂）
  - 商業：連續立面的街屋（一樓店面＋遮陽棚、人行道咖啡座陽傘），大飯店為折線屋頂的 U 型主樓；大型辦公大樓是一段段內縮的玻璃帷幕摩天大樓（窗框直線、頂層機房）
  - 工業：紅磚廠房與鋸齒屋頂、物流倉庫天窗、食品廠筒倉、化工儲槽區（防溢堤與浮頂儲槽）、綠屋頂科技園區；園區內不留空地，沒蓋廠房的街區是貨櫃堆場
- 開局有兩種：**小鎮**（棋盤狀街道與三條大道，只有道路與分區，約 6 個遊戲小時後才開始有人進駐）或**空白地圖**（只有外部連線，沒有分區、預設不自動發展，從零開始）。工業區與住宅至少相隔 250 m。
- 空地塊在該類需求超過門檻（需求條上的虛線，20%）時才會蓋起建築，自動劃設分區的門檻更高（35%），城市依住 / 商 / 工的需求成長；建築會依滿意度升級或衰退，甚至被廢棄（分區保留，之後可再發展）。開啟**自動發展**時，城市也會自己在路旁劃設大小不一的分區。
- **外部連線**：地圖邊緣的高速公路 / 聯外道路帶來過境車流、外地通勤者與原料貨車。
- 收入來自稅收與過路費，支出則是道路與號誌的維護費；所有道路類型與高度層級一開始就全部開放。
- 交通回饋：壅塞或行程失敗太多時，沒有人想搬進來，城市成長會停下來。

### 🗺️ 隨機地圖
- 地圖 3.6 km × 3.6 km（舊存檔維持 2.4 km）。
- **4 種生態系**：溫帶平原、沙漠綠洲、寒帶雪原、熱帶群島（河流、湖泊、島嶼與樹林）。
- **4 種難度**：沙盒（無限資金）、簡單、普通、困難。
- 以種子程序化生成，可無限重玩。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `V` | 選取（查看車輛、建築、路段、路口） |
| `R` | 道路建設：道路（左鍵連續鋪路，右鍵 / `Esc` 結束） |
| `C` | 切換彎道模式 |
| `[` `]` | 切換高度層級 |
| `,` `.` | 切換道路類型 |
| `Shift` / `Alt` | 角度吸附 / 停用吸附 |
| `O` | 圓環 |
| `I` | 交流道（`Q` / `E` 旋轉） |
| `U` | 升級道路 |
| `J` | 路口編輯 |
| `Z` | 分區（沿路拖曳劃設格子） |
| `B` | 拆除 |
| `H` | 壅塞熱圖 |
| `Q` / `E`、右上角 ⟲ ⟳ | 旋轉視角 90°（交流道工具中是旋轉交流道） |
| 滑鼠中鍵左右拖曳 | 自由旋轉視角 |
| `T`、右上角「視角」 | 切換 55° 斜看 / 正上方俯視 |
| `空白鍵` | 暫停 |
| `1` `2` `3` | 一般（1.5×）/ 3× / 8× 速度 |
| 滑鼠拖曳 / `WASD` | 平移 |
| 滾輪 / 雙指 | 縮放 |

遊戲每 3 遊戲小時自動存檔到瀏覽器，也可以從「選單」匯出 / 匯入存檔檔案。

## 執行

純 HTML + JavaScript（ES Modules），沒有任何相依套件，但 ES Modules 需要透過 HTTP 載入：

```bash
python3 -m http.server 8080
```

然後打開 <http://localhost:8080>。也可以直接部署到 GitHub Pages（Settings → Pages → 從 `main` 分支根目錄發布）。

## 測試

模擬核心（路網、交通、經濟）不依賴 DOM，可用 Node.js 18 以上無頭執行：

```bash
npm test   # = node tests/sim.test.js && node tests/interchange.test.js
```

測試內容包含：建立世界、連接外部道路、號誌與全向停車、圓環改建、道路升級與拆除、高架跨越、存讀檔，以及連續模擬 20 遊戲小時的行程成功率；交流道測試會逐一建造每種模板，讓 12 種行向的車流全部通過，並檢查沒有車輛靠死路迴轉繞行。

## 程式架構

| 檔案 | 說明 |
| --- | --- |
| `js/config.js` | 道路類型、高度層級、難度、生態系、分區等參數 |
| `js/util.js` | 亂數、雜訊、折線幾何、二元堆積 |
| `js/terrain.js` | 程序化地形、河流、樹木 |
| `js/network.js` | 節點、路段、車道、路口車道連接與衝突、號誌時相、道路規劃與建造、圓環 |
| `js/routing.js` | 以有向路段為節點、即時車速為成本的路徑搜尋 |
| `js/traffic.js` | 車輛代理人：IDM、變換車道、路口通行判斷、重新選路、停車、公車到站 |
| `js/transit.js` | 大眾運輸：站牌與公車路線自動規劃、派車、乘客上下車 |
| `js/city.js` | 建築、行程產生、滿意度、成長、財務 |
| `js/worldgen.js` | 外部連線與初始小鎮 |
| `js/render.js` | Canvas 2D 繪圖（多層道路、車輛、號誌、熱圖、路口編輯） |
| `js/lotart.js` | 地塊上的建築圖形（歐洲風格：獨棟 / 連棟住宅、周邊式街廓、街屋、飯店、量販店、工業園區） |
| `js/thumbs.js` | 工具列縮圖（道路斷面、圓環、交流道） |
| `js/interchange.js` | 交流道模板：幾何、高度剖面、試建與建造 |
| `js/tools.js` | 玩家工具與輸入 |
| `js/ui.js` | 介面面板與對話框 |
| `js/main.js` | 主迴圈、存讀檔 |

模擬時間：每 0.1 秒一步，1 模擬秒 = 4 遊戲分鐘。參考 Cities: Skylines 的時間膨脹：車子照常速開，時鐘走得快很多（一般速度一天約 4 分鐘、▶▶ 約 2 分鐘、▶▶▶ 約 45 秒）；行程產生率依模擬秒計算，所以時鐘加快不會讓路上車量暴增，但城市成長與收支會加快。
